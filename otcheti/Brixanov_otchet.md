## Спринт 3 (роль — Lead Developer)

**Дата:** День 3
**Участник:** Брюханов Бронислав
**Проект:** Система контроля посещаемости студентов (Android)

### Что сделано

- Создана модель `Attendance` (studentId, lessonDate, subject, status) и константы статусов `AttendanceStatus`.
- Добавлено хранилище `AttendanceRepository` (в памяти): одна итоговая отметка на студента и занятие, повторное сохранение заменяет прежнюю.
- Реализован экран занятия `AttendanceActivity`: выбор группы (Spinner), даты (DatePicker), ввод предмета; валидация предмета.
- Реализован экран отметки `MarkAttendanceActivity`: список студентов группы (по фамилии), RadioGroup на каждого студента, статус по умолчанию «Присутствовал».
- `AttendanceAdapter` хранит выбор в `Map`, а не во View — статусы не «прыгают» при прокрутке.
- Статус можно изменить до нажатия «Сохранить»; при выходе с несохранёнными изменениями — диалог подтверждения.
- Пустой список / нет студентов — понятное сообщение; кнопки блокируются.
- При удалении студента его отметки тоже удаляются.
- Новая Activity зарегистрирована в `AndroidManifest.xml`; README обновлён.

### Доработка по замечанию тестировщика

Замечание: можно было менять посещаемость только по одному предмету за раз; нужна возможность менять отметки по нескольким предметам на экране студента.

- Добавлен `SubjectRepository` — общий список предметов (без дублей, регистр не важен); предмет на экране занятия вводится с подсказками из списка.
- Добавлен экран студента `StudentAttendanceActivity`: за выбранную дату показаны все предметы, у каждого свой RadioGroup; «Сохранить» записывает отметки по всем выбранным предметам одним действием (`AttendanceRepository.saveStudentMarks`).
- Переход на экран студента — нажатием на студента в списке отметки; сохранённое подтягивается обратно в список занятия.
- На экране студента можно сменить дату и добавить новый предмет; при выходе/смене даты с несохранёнными изменениями — подтверждение.

### Критерии готовности

- [x] Три статуса различаются
- [x] Изменение статуса работает до сохранения
- [x] Пустой список обрабатывается понятным сообщением
