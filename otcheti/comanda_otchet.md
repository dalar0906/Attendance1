## 4. Основной пользовательский сценарий

1. Преподаватель открывает экран посещаемости.
2. Выбирает группу и дату занятия.
3. Открывает список студентов выбранной группы.
4. Для каждого студента выбирает статус: «Присутствовал», «Отсутствовал» или «Опоздал».
5. При необходимости меняет статус до окончательного сохранения.
6. Сохраняет итоговые отметки.

Для одного студента в рамках одного занятия должна определяться одна итоговая отметка. Если список студентов пуст, приложение должно показать понятное сообщение.
