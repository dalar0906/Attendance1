## 1. Описание проблемы

Преподаватели колледжа ведут учёт посещаемости вручную — в бумажных журналах, таблицах Excel или заметках. Это создаёт ряд проблем:

- Потеря или повреждение бумажных журналов
- Сложность быстрого поиска информации по конкретному студенту или занятию
- Ошибки при ручном подсчёте пропусков и опозданий
- Отсутствие единой и актуальной картины посещаемости группы
- Большие затраты времени на пересчёт статистики

**Цель приложения** — дать преподавателю простое локальное Android-приложение, которое позволяет:

- вести список студентов по учебным группам;
- отмечать присутствие, отсутствие и опоздание на занятии;
- сохранять историю посещаемости;
- получать базовую статистику.

Приложение предназначено для локального использования на одном Android-устройстве (данные хранятся через Room / SQLite).

## 2. User Stories

### US-01. Главный экран
**Как** преподаватель,  
**я хочу** видеть главное меню с понятными кнопками,  
**чтобы** быстро перейти к нужной функции.

**Критерии приёмки:**
- [ ] При запуске приложения отображается экран с названием приложения
- [ ] На экране есть кнопки: «Студенты», «Отметить посещаемость», «Статистика»
- [ ] Кнопки реагируют на нажатие (осуществляют переход или показывают заглушку)

---

### US-02. Просмотр списка студентов
**Как** преподаватель,  
**я хочу** видеть список студентов с фамилией, именем и группой,  
**чтобы** понимать, кого я отмечаю.

**Критерии приёмки:**
- [ ] Список студентов отображается на экране
- [ ] Для каждого студента видны фамилия, имя и учебная группа
- [ ] При пустом списке показывается понятное сообщение

---

### US-03. Добавление студента
**Как** преподаватель,  
**я хочу** добавлять нового студента (фамилия, имя, группа),  
**чтобы** вести актуальный список группы.

**Критерии приёмки:**
- [ ] Есть форма с полями: фамилия, имя, группа
- [ ] Обязательные поля проверяются (нельзя сохранить пустые или состоящие только из пробелов)
- [ ] После успешного добавления студент появляется в списке
- [ ] Показывается сообщение об успешном добавлении

---

### US-04. Удаление студента
**Как** преподаватель,  
**я хочу** удалять студента из списка,  
**чтобы** убирать ошибочные или ненужные записи.

**Критерии приёмки:**
- [ ] Есть возможность удалить студента
- [ ] Перед удалением появляется диалог подтверждения
- [ ] После удаления список обновляется
- [ ] Приложение не завершается аварийно

---

### US-05. Отметка посещаемости
**Как** преподаватель,  
**я хочу** отметить статус каждого студента на занятии (присутствовал / отсутствовал / опоздал),  
**чтобы** фиксировать посещаемость.

**Критерии приёмки:**
- [ ] Можно выбрать учебную группу и дату занятия
- [ ] Для каждого студента можно выбрать один из трёх статусов
- [ ] Статус можно изменить до окончательного сохранения
- [ ] Пустой список студентов обрабатывается понятным сообщением

---

### US-06. Просмотр статистики
**Как** преподаватель,  
**я хочу** видеть количество присутствий, пропусков и опозданий,  
**чтобы** понимать общую картину посещаемости.

**Критерии приёмки:**
- [ ] Есть экран статистики
- [ ] Отображаются базовые показатели: количество занятий, присутствий, пропусков, опозданий
- [ ] При отсутствии данных показывается понятное сообщение

---

### US-07. Сохранение данных между запусками
**Как** преподаватель,  
**я хочу**, чтобы данные сохранялись между запусками приложения,  
**чтобы** не вводить всё заново.

**Критерии приёмки:**
- [ ] После перезапуска приложения студенты остаются в списке
- [ ] Отметки посещаемости сохраняются
- [ ] Данные не пропадают при закрытии приложения

## 3. Основные экраны приложения

| Экран | Activity | Назначение | Основные элементы |
|-------|----------|------------|-------------------|
| **Главное меню** | `MainActivity` | Точка входа в приложение | Название приложения + кнопки «Студенты», «Отметить посещаемость», «Статистика» |
| **Студенты** | `StudentsActivity` | Работа со списком студентов | Список студентов, кнопка «Добавить», возможность удаления |
| **Отметка посещаемости** | `AttendanceActivity` | Фиксация статусов на занятии | Выбор группы и даты, список студентов с выбором статуса |
| **Статистика** | `StatisticsActivity` | Просмотр итогов посещаемости | Показатели присутствий / пропусков / опозданий |

## 5. Примечания Product Owner

- Минимальная карточка студента: идентификатор, фамилия, имя, учебная группа.
- Запись о посещаемости: студент, дата занятия, дисциплина/тема, статус, комментарий (необязательно).
- Статусы: «Присутствовал», «Отсутствовал», «Опоздал».
- Приложение работает локально, без сервера и интернета.
- Для демонстрации использовать только вымышленные данные студентов.
