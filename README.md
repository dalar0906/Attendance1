# AttendanceControl — Система контроля посещаемости студентов

Мобильное Android-приложение для учёта посещаемости студентов колледжа.

**Стек:** Kotlin • Android Studio • XML (View-based) • Room (SQLite) • Git

---

## Описание

Приложение предназначено для преподавателя / куратора учебной группы.  
Позволяет вести список студентов, создавать занятия, отмечать присутствие / отсутствие / опоздание, просматривать историю и получать простую статистику.

**Особенности:**
- Локальное хранение данных (Room / SQLite)
- Работает без интернета
- Классический View-based интерфейс (XML + Activity)
- Простая и понятная структура

- Студенты и отметки посещаемости хранятся в памяти приложения (`MutableList`).

- Постоянное хранение (Room/SQLite) — в спринте 4.

## Спринт 3 — занятия и отметка посещаемости

- `AttendanceActivity` — экран занятия: группа (Spinner), дата (DatePicker), предмет.
- `MarkAttendanceActivity` — список студентов группы; у каждого RadioGroup:
  «Присутствовал» / «Отсутствовал» / «Опоздал». Статус можно менять до нажатия «Сохранить».
- Одна итоговая отметка на студента и занятие (дата + предмет): повторное сохранение заменяет прежнюю.
- Пустая группа / нет студентов — понятное сообщение.
- При выходе с несохранёнными изменениями показывается подтверждение.
- **Список предметов** (`data/SubjectRepository.kt`): предметы сохраняются в общий список (без дублей, регистр не важен) и подсказываются на экране занятия.
- **Экран студента** (`StudentAttendanceActivity`): нажмите на студента в списке отметки → за выбранную дату видны все предметы, по каждому свой статус; кнопка «Сохранить» записывает отметки по нескольким предметам сразу. Дату можно сменить, новый предмет — добавить прямо на этом экране.
- Модель: `data/Attendance.kt`, хранилище: `data/AttendanceRepository.kt`.
