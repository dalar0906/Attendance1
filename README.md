# AttendanceControl — Система контроля посещаемости студентов

Мобильное Android-приложение для учёта посещаемости студентов колледжа.

**Стек:** Kotlin • Android Studio • XML (View-based) • Room (SQLite) • Git

---

## Описание

Приложение предназначено для преподавателя / куратора учебной группы.  
Позволяет вести список студентов, создавать занятия, отмечать присутствие / отсутствие / опоздание, просматривать историю и получать простую статистику.

**Особенности:**
- Локальное хранение данных (Room / SQLite)
- Работает без интернета
- Классический View-based интерфейс (XML + Activity)
- Простая и понятная структура

## Ограничения (спринт 2)

- Данные студентов хранятся в памяти приложения (`MutableList`).
- После полного перезапуска список очищается.
- Постоянное хранение (Room/SQLite) — в спринте 4.

## Структура данных

### Student

Карточка студента содержит:

- `id` — идентификатор;
- `firstName` — имя;
- `lastName` — фамилия;
- `groupName` — учебная группа.

### Attendance

Запись о посещаемости содержит:

- `studentId` — идентификатор студента;
- `lessonDate` — дата занятия;
- `subject` — дисциплина или тема;
- `status` — статус посещаемости.

Допустимые значения статуса: `Присутствовал`, `Отсутствовал`, `Опоздал`.

Отдельная сущность `Lesson` может использоваться для хранения занятия. Решение о её выделении принимается командой совместно с Lead Developer. Если отдельная сущность не используется, дата и дисциплина или тема хранятся в `Attendance`.

## Хранение данных

На раннем этапе проекта данные студентов хранятся во временной коллекции приложения (`MutableList`). Такое хранение не обеспечивает сохранность данных после полного перезапуска.

В Спринте 3 предусматривается сохранение отметок в текущем сеансе приложения. Цель Спринта 4 — перейти на локальную базу Room / SQLite. После реализации этого этапа добавление, чтение и удаление данных должны выполняться через DAO, а сохранённые студенты, занятия и отметки должны оставаться доступными после повторного запуска приложения.
